# ICNative - Documentation Hub

## 📑 Danh mục Tài liệu

1. **[Kiến trúc Tổng thể Hệ thống (Architecture)](ARCHITECTURE.md)**  
   Mô hình hoạt động End-to-End từ Flutter Client, On-Device Vision Engine, Firebase Backend 0 VNĐ cho đến iOS WidgetKit & Android RemoteViews.

2. **[Đặc tả Thuật toán Neo Sticker (Anchoring Engine)](ANCHORING_ENGINE.md)**  
   Toán học hình học & thị giác máy tính On-Device: Trích xuất ROI, tìm điểm cực trị (Apex/Extreme Points), tính vector pháp tuyến và ma trận Affine để dán meme khớp tự nhiên.

3. **[Tích hợp Home Screen Widget (Widget Integration)](WIDGET_INTEGRATION.md)**  
   Hướng dẫn chi tiết thiết lập `home_widget`, App Groups trên iOS, SwiftUI WidgetKit, Android `AppWidgetProvider`, và Silent Push Notification qua FCM.

4. **[Nhật ký Báo cáo Công việc (Work Log)](WORK_LOG.md)**  
   Nơi lưu trữ lịch sử báo cáo công việc theo thời gian thực của các AI Agent và lập trình viên (tuân thủ quy tắc bắt buộc tại [agent.md](../agent.md)).
